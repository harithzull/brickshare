# BrickShare frontend

The main application uses React 18, Vite, and ethers.js v5.
Follow the [root setup and run guide](../README.md) for the full local workflow.

Visitors can browse live listings without connecting a wallet. The marketplace
includes search, filters, property details and an explicit fictional sample
preview. Connected wallets get a holdings dashboard, transfer history, and
transaction review with estimated gas. Administration retains add/withdraw.

From the repository root:

```sh
npm run setup
npm run compile
# Keep npm run node running in a separate terminal.
npm run deploy:local
npm run dev
```

## Files

- `src/App.jsx`: wallet connection, listings, forms, and transactions.
- `src/App.css`: application styles.
- `src/config.js`: loads the generated contract configuration.
- `src/hooks/useMarketplace.js`: read-only listing, holdings and history loading.
- `src/lib/marketplace.js`: exact token arithmetic, validation, filters and event reads.
- `src/data/property-metadata.json`: optional deployment-scoped descriptions,
  photographs and documents; see [metadata guide](PROPERTY_METADATA.md).
- `src/generated/RealEstateTokenization.abi.json`: generated by root compilation
  and deployment; commit this file after contract changes.
- `src/generated/deployment.json`: generated by deployment and ignored by Git.

Do not paste addresses or edit the ABI by hand. Restart Vite after deployment,
especially when the deployment file did not exist when Vite started.

The app can build without a deployment, but connecting a wallet requires one.
For a working production demo, deploy before `npm run build` so the address is
included in the bundle. A node restart requires redeployment and a new build.

You can also run `npm run dev`, `npm run build`, and `npm run preview` from this
directory. Those commands operate on the frontend only.

Run `npm test` in this directory for frontend data/validation tests, or
`npm run test:frontend` from the repository root.
