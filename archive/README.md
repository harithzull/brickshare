# Historical implementations

The supported application is now `../react-frontend/`. These files are preserved
for reference and are not included in the main build or test suite.

| Path | Purpose |
| --- | --- |
| `frontend-prototype/` | Early standalone HTML implementation using ethers v6 |
| `realestate-frontend/` | Alternative plain HTML interface using ethers v5 |
| `Lock.sample.js` | Unused Hardhat scaffold test for a contract no longer present |

The original README files are historical notes; their network and setup
instructions may be outdated. The HTML versions retain their old configuration
and do not receive generated deployment updates. Use the root README and React
application for current development.
